## 无自动化回归的原因

本机实测：对 Playwright 启动的 Chrome App 窗口，Windows 合成鼠标/键盘（`SetCursorPos`/`SendKeys`）**不可靠**——
- DPI 150%（144 dpi）下逻辑/物理坐标混用；
- 光标在设置后 600ms 内被其他进程移动（实测 500,500 → 463,687）；
- 前台被其他窗口抢占，点击落到遮挡窗口。

因此 UI 层验证改用 Playwright 的 `page.mouse`（CDP 注入）或人工操作；**不要把合成输入当作自动化回归手段**。
