## 无自动化回归的原因

本机实测：对 Playwright 启动的 Chrome App 窗口，Windows 合成鼠标/键盘（`SetCursorPos`/`SendKeys`）**不可靠**——
- DPI 150%（144 dpi）下逻辑/物理坐标混用；
- 光标在设置后 600ms 内被其他进程移动（实测 500,500 → 463,687）；
- 前台被其他窗口抢占，点击落到遮挡窗口。

因此 UI 层验证改用 Playwright 的 `page.mouse`（CDP 注入）或人工操作；**不要把合成输入当作自动化回归手段**。

## 跨页面作品识别矩阵（2026-11-25，16-save-video v3.2）

测试方式：Playwright 独立实例 + profile 副本，DOM 点击下载按钮，读取 `[DouyinSave] resolve` 日志。

| 页面 | 结果 | 识别来源 |
|---|---|---|
| 详情页 `/video/{id}` | 正确锁定 | `url:path` |
| 他人主页 `?modal_id=` | 正确锁定 | `url:modal_id` |
| 自己主页 `?modal_id=` | 正确锁定 | `url:modal_id` |
| 搜索页 `?modal_id=` | 正确锁定 | `url:modal_id` |
| 推荐页 / 精选页 / 关注页 / 朋友页 | 拒绝（`ids=[]`） | 页面无可识别标识，**未验证** |
| 设置页（无作品） | 正确拒绝 | — |

注：拒绝是设计行为（无标识时宁可拒绝也不乱下），但推荐页在正式应用中能识别（历史日志有成功下载记录），测试实例差异原因未查明。
